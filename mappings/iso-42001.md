# Mapping: ISO/IEC 42001:2023 Annex A

How operating an agent under this framework produces evidence for the 38 Annex A controls.

**Caveats**

- This framework governs runtime operation of agents. It does not replace an AI management system (AIMS), and following it does not make an organization ISO 42001 certified.
- Annex A is a reference set. Controls are selected through a Statement of Applicability based on risk and impact assessments.
- Control titles below follow public summaries; check them against the licensed standard text.

**Status**

- **Evidenced**: framework controls produce direct evidence for the control.
- **Contributes**: framework artifacts help, but the control needs organizational process.
- **Outside scope**: not addressed by the framework.
